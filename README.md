
# Elan Client

**Minecraft, Your Way.**

Elan Client is an independent, personal and non-commercial
Minecraft Java Edition launcher project developed by
**OhneElan (YourDarky)**.

The project aims to provide a modern launcher experience
with a clean user interface, Minecraft version management,
and free client-side cosmetic customization.

> **Project Status:** In active development.
> Elan Client is currently intended for private use only.

## 🌐 Official Project Website

https://yourdarky.github.io/elan-client/

## ✨ Features

### Launcher Interface
- Modern dark Liquid Glass design
- Customizable launcher settings
- Minecraft Java Edition version selection
- Windows desktop application

### Microsoft Authentication
- Microsoft OAuth 2.0 authentication with PKCE
- Intended for legitimate Minecraft Java Edition accounts
- Xbox Live and Minecraft Services integration
- Authentication integration is currently in development

### Client-Side Cosmetics (Planned)
- Custom capes
- Cosmetic wings
- Character accessories
- Free cosmetic customization

Cosmetics are intended to be rendered locally and
do not require modifications to Minecraft servers.

## 🔐 Authentication and Account Security

Elan Client is designed to use Microsoft's official
authentication flow.

The intended authentication process includes:

1. Microsoft account sign-in using OAuth 2.0 with PKCE
2. Xbox Live authentication
3. Xbox Security Token Service (XSTS) authentication
4. Minecraft Services authentication
5. Minecraft Java Edition ownership and profile verification

The application is not intended to collect or store
Microsoft account passwords.

Microsoft and Minecraft authentication integration
is still under development and may require additional
application permissions or approval.

## 🎯 Project Purpose

Elan Client is being developed as a personal software
project to explore desktop application development,
launcher functionality and Minecraft customization.

The application is not currently intended for public
distribution or commercial use.

There are no planned paid cosmetics or subscription
features.
